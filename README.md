# 학급 선거 용지 제작 사이트

대한민국 선거 투표용지의 레이아웃(제목, 기호/성명/정보/기표란 표 구조)을 참고해 만든 학급용 편집 툴입니다.

## 실행 방법

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 주요 기능

- 선거명, 투표구, 일시, 선거관리기관 문구 수정
- 후보자 무제한 추가/삭제 및 기호/이름/정보 개별 수정
- 용지 크기, 기본 글자 크기, 후보 행 높이 조정
- 인쇄/PDF 저장 지원

## 주의

- 실제 공직선거 사용 목적이 아닌 **학급 교육 활동용** 템플릿입니다.
